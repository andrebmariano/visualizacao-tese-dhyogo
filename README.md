# Visualização da tese — Dhyogo

Visualização interativa do modelo da tese do Dhyogo, em um único arquivo HTML offline (`index.html`), publicada via GitHub Pages para consulta no celular.

Dados: **resultados v3 finais** (ΔT_cf ≤ 10 K). Inclui 41 painéis didáticos por equação e layout para celular.
